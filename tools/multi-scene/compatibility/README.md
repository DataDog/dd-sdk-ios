results live under `DatadogRUM/MultiSceneSupport/Results/EXP-226-platform-*`.
It does not approve API promotion, runtime behavior or any Session Replay content.

dependencies. Git object alternates must resolve relatively inside the copied
cache. It freezes source/checkouts/bare repositories, protected workspace state,
compiler flags, every architecture's source membership, emitted modules, private
objects, actual link lists/final products and privacy resources.

contained an Xcode diagnostic before JSON. `platform_execution.py` qualifies that
exact saved response and runs only the still-unexecuted builds. Original failure
and cleanup receipts remain immutable. The continuation must not repeat discovery.
Every stage requires its exact plan, passing controls and designated review.

Both drivers use the existing bounded command collector. They reject competing
compiler/linker/resource/signing workloads, stop on the first unsuccessful cell,
retain raw output before decoding and preserve separate scenario, evidence and
cleanup verdicts. Output folders and deadlines are single-use.
