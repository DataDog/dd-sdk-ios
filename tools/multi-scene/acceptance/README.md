# Multi-scene acceptance workflow

Select the owning result from [the restart cursor](../../../.continue-here.md),
then read only the matching procedure below. This router grants no native admission.
[Remaining release work](../../../DatadogRUM/MultiSceneSupport/REMAINING_WORK.md)
is generated from the register and current owners.

## Choose a workflow

| Workflow | Contract |
| --- | --- |
| [Generic simulator runner](docs/RUNNER.md) | Fresh build, selected inventory, clean installation and exact local/backend owners. |
| [Telemetry adapters](docs/TELEMETRY.md) | Named Resource, error, mutation, Trace, Logs, WebView and vitals contracts. |
| [Physical prerequisites](docs/PHYSICAL.md) | Installed-code identity, device readiness and controlled-app inventory. |
| [H04 activation](docs/H04.md) | Serial foreground scene ownership; does not prove an uninterrupted visible peer. |
| [H10 backgrounding](docs/H10.md) | Independent A background/return with B ownership and native continuity. |
| [H06 Operations](docs/H06.md) | Simultaneously visible owners, ordered Operations and task-only cleanup. |
| [Display capture](docs/CAPTURE.md) | Source observation, silent recording, decoding and recorder/session integration. |
| [Human sessions](docs/HUMAN.md) | Reviewed product reuse, operator readiness and Resource/Trace fold capture. |

The fresh-build runner's recipe applies only to its named contracts. Prepared
human and physical paths can reuse a reviewed product when the owning result
binds unchanged source, helper, compiler, binary and scope identities. Do not
rebuild or rerun accepted evidence merely to follow the generic recipe.

## Shared contract

- Qualify event attribution and View/Navigation/Action capture under the
  [project measurement rule](../../../DatadogRUM/MULTI_SCENE_SUPPORT.md#measurement-and-testing-rule).
  Timing is diagnostic; operational timeouts bound work and cleanup.
- Preserve raw evidence and separate scenario, evidence and cleanup verdicts.
  A build, component control or saved replay is not native gate acceptance.
- Require fresh prerequisites before critical work; no consumed readiness, reused
  run IDs, late boundary substitution or active deadline extension.
- Use supported tools for actual input and retain their returned observations.
  Assert owned scenes/windows/controllers and real display geometry, not window
  counts or a simulator sidebar icon. Round geometry to the applicable pixel grid.
- Keep original INVALID attempts immutable. Later restoration is separate proof.
  Failed capture or delayed batching alone does not establish an SDK regression.
- Preserve protected files and keep credentials/raw payloads out of public artifacts.
  Commit explicit task paths, sign when available, use the authorized local fallback
  when unavailable, and never push without separate authorization.
